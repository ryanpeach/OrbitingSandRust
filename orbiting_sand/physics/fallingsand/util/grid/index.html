A simple 2d grid type This was originally created seperate from the ndarray crate, but it was later decided to use the ndarray crate as the backend for this type. This is because the ndarray crate has a convolution function that is helpful for the physics simulation. So some of this code is now redundant, but is maintained for legacy reasons
